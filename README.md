🤖 Agente de IA - Imersão de Inteligência Artificial (Alura)

Este projeto foi desenvolvido durante a Imersão de IA da Alura, com o objetivo de explorar conceitos práticos de Inteligência Artificial, modelos de linguagem e automações com agentes inteligentes.
O notebook demonstra o uso de técnicas modernas de IA para criar um agente interativo, capaz de compreender, processar e responder a diferentes tipos de solicitações.

🚀 Objetivo do Projeto

Criar um agente de IA que:

Interaja de forma autônoma com o usuário;

Utilize modelos de linguagem avançados (LLMs);

Possa executar tarefas automatizadas e realizar raciocínios simples;

Sirva como base para aplicações futuras de IA generativa.

🧠 Tecnologias e Bibliotecas Utilizadas:

Python 3.10+

Jupyter Notebook

OpenAI API / LLMs

LangChain (para criação de agentes e fluxos de pensamento)

pandas (para manipulação de dados)

dotenv (para gerenciamento de variáveis de ambiente)

requests, os, json (para integrações e automação)


⚙️ Como Executar o Projeto.

Clone o repositório:

git clone https://github.com/seu-usuario/agente_de_IA.git
cd agente_de_IA
Crie um ambiente virtual (opcional, mas recomendado):

python -m venv venv
source venv/bin/activate  # no Windows: venv\Scripts\activate
Instale as dependências:

pip install -r requirements.txt
Configure a chave da API da OpenAI:
Crie um arquivo .env com o seguinte conteúdo:

OPENAI_API_KEY="sua_chave_aqui"
Execute o notebook:
Abra o arquivo agente_de_IA.ipynb no Jupyter Notebook e execute as células na ordem.
